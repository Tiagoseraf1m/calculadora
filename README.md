🖥️ Calculadora com Interface Gráfica

Este projeto é a versão final da calculadora, implementada em Java com Swing.
Ela traz uma interface gráfica simples e funcional para realizar operações matemáticas básicas.

✨ Funcionalidades

Interface gráfica feita com Java Swing

Operações suportadas: adição (+), subtração (-), multiplicação (*) e divisão (/)

Botão C para limpar o visor

Exibição do resultado na própria interface

📂 Estrutura do Projeto

O projeto possui duas classes principais:

Calculadora.java → contém a lógica dos cálculos matemáticos.

Interface.java → responsável pela interface gráfica (GUI) e interação do usuário.

🚀 Como Executar

Compile os arquivos Java:

javac Calculadora.java Interface.java


Execute o programa pela classe principal da interface:

java Interface

🖼️ Demonstração

🔢 A interface apresenta um visor na parte superior e os botões numéricos e operadores organizados em uma grade 4x4.

Exemplo de uso:

Digite um número

Clique em um operador (+, -, *, /)

Digite outro número

Pressione = para visualizar o resultado

Use C para limpar a tela
